## 1. Design Language Overview

**Vibe:** vibrant · soft · Dark theme

**Design rhythm:** 4px grid · subtly rounded · flat (no shadows)

## 3. Typography

- **Heading:** DM Sans 700
- **Body:** DM Sans 16px 400, 1.5 line-height
- **Scale:** 16px

## 4. Spacing & Layout

- **Spacing scale:** 4,8,12
- **Border radius:** 8px buttons, 16px cards
- **Radius vocabulary:** button → 8px
- **Spacing tokens:** `--font-size-title-special: 80px`, `--letter-spacing-title-special: -.005em`, `--font-size-title-special-bold: 80px`, `--letter-spacing-title-special-bold: -.005em`, `--font-size-title-special-medium: 80px`, `--letter-spacing-title-special-medium: -.005em`

## 6. Component Specs

### Button
- #34D399 bg
- #FFFFFF text
- 8px radius
- 6px 10px padding
- 600 weight

### Card
- #1D1E20 bg
- 1px solid #262831
- 16px radius

### Input
- default input

## 7. Implementation Rules

**DO:**
- Use `#34D399` for all primary CTAs and interactive accents
- Reserve `#673DE6` for accent moments — don't overuse
- Stick to the spacing scale (4,8,12) — don't introduce arbitrary values
- Match the radius vocabulary: 8px buttons, 16px cards
- Pair DM Sans 700 headings with DM Sans 16px 400, 1.5 line-height
- Honour the visual hierarchy: bold colour on primary actions, muted tones on secondary

**DON'T:**
- Copy this design verbatim — use the tokens as a system to build something original
- Mix in colours outside this palette (especially competing primary colours)
- Break the radius scale by introducing one-off values
- Use the same shadow tier for everything — match elevation to importance
